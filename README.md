# Курсовой проект "Сетевой чат"

Консольное клиент-серверное приложение на Java.

## Возможности
* Многопользовательский чат.
* Логирование всех событий в `file.log`.
* Настройка порта через `settings.txt`.
* Корректный выход по команде `/exit`.

## Стек
* Java 24
* Maven
* JUnit 5

## Запуск
1. Собрать проект: `mvn clean package`.
2. Запустить Сервер: `ru.netology.Server`.
3. Запустить Клиента: `ru.netology.Client`.
